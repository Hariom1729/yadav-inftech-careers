## 🚀 Overview

**Yadav Inftech** initially appears as an elite, tier-1 Silicon Valley tech enterprise specializing in fault-tolerant distributed systems, neural AI inference clusters, and quantum-resistant security architectures.

Candidates browse open engineering positions, explore global offices (Bengaluru, San Francisco, London, Singapore), and complete a comprehensive multi-step application form.

However, upon reaching the final step to submit the application... **The Submit Button runs away from the cursor!**

---

## ✨ Features

### 1. 🌐 Modern 3D & Glassmorphic UI
- **Three.js Interactive Background**: Floating iridescent 3D geometric crystals (Icosahedrons, Torus Knots, Dodecahedrons, wireframe geometries) with mouse parallax tracking and ambient starfields.
- **Electric Dark Theme**: Deep navy/black (`#030712`) with electric blue and cyan glassmorphism panels.
- **Zero Asset Audio Synthesizer**: Uses Web Audio API for aerodynamic swooshes when the button dodges, and a triumphant fanfare chime when the prank is revealed.

### 2. 💼 Enterprise Careers Portal
- **Hero Section**: *"Build Your Future With Us"* with live global metrics.
- **Engineering Pillars**: Distributed core, Generative AI inference, Zero-Trust defense, WebGPU real-time rendering.
- **Open Positions**: Searchable, filterable by department (*Engineering*, *AI Research*, *Infrastructure*, *Security*, *Design*) with salary disclosures, tech tags, and direct application links.
- **Global Presence**: Information on innovation hubs across 4 continents.

### 3. 📝 Comprehensive Application Form
- Step 1: Personal & Contact Information (Name, Email, Phone, Location, LinkedIn, GitHub)
- Step 2: Academics & Technical Skills (Degree, College, Grad Year, interactive skill selector + custom tags)
- Step 3: Experience & Resume (Drag-and-drop resume upload with PDF/DOC/DOCX validation and upload scanning bar)
- Step 4: Dossier Review & Final Submission Gateway
- *Convenience feature: Top-right "Autofill Sample" button for fast testing.*

### 4. 🏃💨 The Escaping Submit Button Prank
- The final **`SUBMIT APPLICATION →`** button detects cursor proximity.
- When cursor comes within 95px, the button calculates vector escape physics and springs across the container.
- Mobile friendly: Tapping on mobile triggers an immediate evasive dodge.
- Random dynamic speech bubbles pop up with hilarious remarks:
  - *"Oops! Too slow 😂"*
  - *"Are you really trying to catch me?"*
  - *"Your future is running away!"*
  - *"Yadav Inftech security is too strong!"*
  - *"The HR team is watching you 👀"*

### 5. 🏆 Prank Reveal & The Grand Finale
- After 6 evasion attempts, the candidate receives the prompt:
  > *"Congratulations! You have successfully completed our most difficult interview round: The Elusive Submit Button Challenge."*
- Unlocks the full-screen celebration:
  - **Confetti Explosion** (`canvas-confetti`)
  - **Triumphant Fanfare audio**
  - **Personalized Assessment** using the candidate's name and applied role
  - **"Get Offer Letter"**: Downloadable / printable honorary Certificate of Merit appointing them as *"Chief Elusive Button Wrangler"*
  - **"Prank Friends"**: Instant link copy to challenge friends and colleagues.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism
- **3D Graphics**: Three.js
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVGs
- **Celebration Effects**: Canvas Confetti
- **Audio**: Native Web Audio API (Synthesized)

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Hariom1729/yadav-inftech-careers.git
   cd yadav-inftech-careers
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
